# 📂 Auto File Sorter (Organizador de Arquivos)

Um script em Python simples e eficiente projetado para organizar automaticamente a pasta de Downloads (ou qualquer outro diretório) movendo arquivos para pastas categorizadas de acordo com suas extensões.

## 🚀 Funcionalidades

- **Categorização Automática:** Separa arquivos por tipo (Imagens, Documentos, Áudios, Vídeos, Compactados e Programas).
- **Pasta "Outros":** Arquivos não mapeados são movidos com segurança para uma pasta dedicada.
- **Criação Dinâmica de Pastas:** As pastas de destino só são criadas quando um arquivo correspondente é encontrado.
- **Leve e Rápido:** Utiliza apenas módulos nativos da linguagem (`os` e `shutil`), sem dependências externas.
